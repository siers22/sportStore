# Открытие проекта в Visual Studio

В корне репозитория находится `SportStore.sln`. Внутри решения один проект — `SportStore/SportStore.csproj` со всем C# кодом, Razor-страницами и CSS.

## Что установить

- Visual Studio 2022 версии 17.8 или новее либо Visual Studio 2026.
- Компонент **ASP.NET and web development** и .NET 8 SDK.
- Интернет для первого восстановления пакетов NuGet.

## Как запустить

1. В Visual Studio выберите **Файл → Открыть → Проект или решение** и откройте `SportStore.sln`. Открытие самой папки включает режим «Представление папок», в котором `Program.cs` ошибочно предлагается как отдельная цель запуска.
2. В «Обозревателе решений» должен появиться верхний узел **«Решение SportStore (1 проект)»**, а под ним проект **SportStore**. Если он не выбран как запускаемый, нажмите правой кнопкой на проект и выберите **«Назначить запускаемым проектом»**.
3. Дождитесь восстановления NuGet-пакетов, выберите профиль **SportStore** и нажмите **F5**. Страница откроется по адресу `http://localhost:5080`.
4. Для остановки нажмите кнопку Stop в Visual Studio.

SQLite-база `sportstore.db` создаётся автоматически в `SportStore/bin/Debug/net8.0`. PostgreSQL и Docker не нужны. Демо-вход покупателя: `buyer@sport.local` / `Demo123!`. Остальные аккаунты перечислены в [README.md](README.md).

Если сборка не проходит, откройте **Вид → Вывод → Сборка** и прочитайте первое сообщение об ошибке. Если Windows блокирует запуск, сохраните текст системного предупреждения: политика защиты может относиться и к файлам, собранным из исходников.
